# 2026-10-13 이름 후보와 개발 초안 검토

사용자 확인: GM 모드는 말 그대로 초안이며, 처음 구상한 주요 시스템은 아직 대부분 반영되지 않았다. 현재 검사 통과를 전체 기획 완성으로 해석하지 않는다.

## 이름 후보 (미확정)

- 다이아몬드 레거시: 선수의 성장과 구단의 역사를 함께 담는다. 우선 추천.
- 다이아몬드 스토리: 캐릭터·학교생활과 구단 이야기에 어울린다.
- 베이스볼 라이프: 선수와 단장으로 살아가는 두 경로를 담는다.
- 베이스볼 유니버스: 두 모드와 향후 리그 확장을 포괄한다.

구단명은 현재 서울 트윈스·서울 베어스·인천 랜더스처럼 원 구단명에 도시만 붙인 형태보다 더 변형할 필요가 있다. 예시 후보는 서울 더블윙스, 서울 아이언베어즈, 인천 하버호크스, 수원 아르카나, 대전 블레이즈다. 이름은 확정하거나 코드에 적용하지 않았다.

## 파일 확인

- 최근 로컬 미커밋 변경에 선수 세이브 복원, 전후반기 주말리그 순위표, GM 대시보드·리그·로스터 화면이 있다.
- GM 기초 코드에는 10개 구단/가상 선수 생성, 구단 선택, 일정 자동 진행, 순위/개인 기록, 1·2군 변경, 타석별 경기와 작전 버튼이 있다.
- 자동 검사 106개와 정적 검사, 배포 빌드가 통과했다. 브라우저 실제 플레이와 전체 GM 시즌 완주는 검증하지 않았다.

## 우선 확인할 문제

1. src/store/proLeagueStore.ts:269~323: 관전 결과를 반영한 뒤 simulateDay가 같은 날짜 모든 경기를 다시 계산한다. 관전 경기 전적과 개인 기록이 중복 집계될 수 있다.
2. src/db.ts:25~31: 기존 구단에 code가 없으면 구단·프로 선수·시즌 저장을 지우는 초기화 경로가 있다. 기존 프로 저장 보존을 확인해야 한다.
3. src/store/proSimulation.ts:37 및 타자/투수 선택: rosterTier를 제외 조건으로 쓰지 않아 2군 선수도 경기 계산에 포함된다.
4. src/data/weekendLeague.ts: 플레이어 승패에 고정 5:2 득점을 붙이고 다른 팀 경기를 임의 추산한다. 실제 조별 전체 경기 기록을 반영하는 순위표는 아니다.
5. GM 핵심 기획의 구현 범위와 완료 기준을 다시 정해야 한다. 드래프트·트레이드·계약/재정·육성 커리어 연결이 현재 초안 화면만으로 완성되었다고 평가하지 않는다.

기존 로컬 초안 소스는 수정하거나 커밋하지 않았다. 이 기록만 별도 검토 브랜치와 Drive에 보관한다. 릴리스 버전 2.1.1은 유지한다.

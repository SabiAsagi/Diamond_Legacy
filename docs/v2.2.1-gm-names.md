# 2.2.1 GM 세계 연결과 이름 편집

독립 GM 시작과 졸업 선수 연결을 기존 기획의 첫 단계로 구현했다. 졸업 선수를 연결하면 원본 선수 저장은 유지하고 같은 세계 연도의 드래프트 후보로 복사한다. 실제 드래프트 선발은 후속 단계다.

## 기본 구단명

| 지역 | 이름 |
|---|---|
| 서울 | 듀오스 · 그리즐리스 · 가디언즈 |
| 인천 | 보이저스 |
| 수원 | 메이지스 |
| 대전 | 호크스 |
| 광주 | 재규어스 |
| 대구 | 레오스 |
| 부산 | 샤크즈 |
| 창원 | 랩터스 |

끝 글자 변형 대신 기존 이름의 의미와 이미지를 닮은 단어를 사용했다. GM 대시보드의 ‘구단·선수 이름 편집’에서 전체 구단명, 약칭, 구장명과 프로 선수·드래프트 후보 이름을 수정할 수 있다. 저장 ID, 성적과 능력치는 유지한다. 사용자 지정 구단명은 다음 초기화 때 기본 이름으로 되돌리지 않는다. 진행 중인 경기에서는 이름 편집을 차단한다.

## 검증

- 자동 검사 112개 통과: 기존 1학년 완주 통합 검사 포함.
- 린트와 배포 빌드 통과.
- 별도 로컬 테스트 저장에서 부산 구단명·약칭·구장명과 선수 이름을 수정하고 새로고침 후 유지되는 것을 확인.
- 졸업 선수 복사, 저장 실패 롤백, 기존 저장 보존은 자동 검사로 확인했다. 전체 GM 시즌의 실제 플레이 검증은 수행하지 않았다.

## 남은 초안 범위

안티그라비티의 GM 초안을 함께 보존한다. 라이브 경기 종료 후 같은 경기의 중복 시뮬레이션, 1·2군 구분과 경기 출전 연결, 주말리그의 임시 점수 계산은 후속 보완 대상이다. 드래프트·트레이드·계약·재정 운영 전체가 완성된 상태는 아니다.
